# vivo 闹钟方案 3.0

面向 vivo `com.android.BBKClock` 8.0.3.10 的本地闹钟方案管理器。

## 产品入口

- 安装后只有一个固定主图标“vivo 闹钟方案”。
- 打开主应用只管理方案，任何“保存/完成”都不会创建真实闹钟。
- 每套已保存方案可由用户添加一个桌面快捷方式。
- 只有点击方案快捷方式才执行：捕获一次统一 `t0`，计算整套目标，依次交给 vivo 时钟并由本应用无障碍服务自动执行“完成”。
- 不需要 Tasker 或 MacroDroid。

首次初始化保留默认方案：`+480 / +495 / +500` 分钟。旧 2.x 版本保存的偏移方案会迁移为完整的逐闹钟配置；方案 ID 保留，因此已有可更新的配置快捷方式不会执行错方案。

## 配置能力

每个闹钟独立保存：

- 相对 t0 偏移或绝对时分/日期；
- 完整重复规则（含自定义、单双休和 2～62 天轮班周期）；
- 名称；
- 系统/默认/天气/静音/自定义铃声和全部振动效果；
- 一次性关闭后删除；
- 稍后提醒开关、间隔、次数、稍后提醒报时；
- 语音播报及天气、待办、快递、新闻的启用和顺序。

详细 APK 字段依据见 [vivo 配置项核对](docs/vivo-alarm-config-audit.md)。

- 版本：3.0.0（versionCode 5）
- 签名 SHA-256：`9e6dcd45db0496ee3327a66971da1ae6815ae848537e58a8b38219572559b84e`

本版本尚不能仅凭编译结果宣布完成。请按 [实机验收顺序](docs/real-device-acceptance.md) 从“不误执行”和单闹钟 +3 分钟测试开始。
