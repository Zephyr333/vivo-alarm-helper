# vivo 闹钟方案 3.2.0

面向 vivo `com.android.BBKClock` 8.0.3.10 的本地闹钟方案管理器。

> 非 vivo 官方项目。3.1.1 的核心创建、自动完成和无障碍恢复链路已在
> vivo X100 Pro（PD2324C）、系统 `PD2324C_A_16.2.12.0.W10.V000L1`、
> 时钟 8.0.3.10 上通过实机验证。3.2.0 新增的应用内执行、执行时选择
> 第一个时间、后续间隔和方案排序仍建议先在同一设备上做短时闹钟验收。

## 产品入口

- 安装后只有一个固定主图标“vivo 闹钟方案”。
- 打开主应用只管理方案，任何“保存/完成”都不会创建真实闹钟。
- 每套已保存方案都可在主应用中直接“执行”，也可添加一个桌面快捷方式。
- 多套方案可通过卡片右上角的 `≡` 长按拖动排序，顺序会立即保存在本地。
- 两个入口使用同一条执行链路：只获取一次点击时刻，计算整套目标，依次交给 vivo 时钟并由本应用无障碍服务自动执行“完成”。
- 不需要 Tasker 或 MacroDroid。

## 3.1.1 无障碍可靠性

- 状态判断同时核对系统授权和服务生命周期，兼容 vivo 返回的完整及缩写组件名。
- 已授权但服务正在恢复时，快捷方式会持久保存一次待执行任务；服务连接后自动领取并继续。
- 等待过程中应用进程被回收，也不会丢失刚刚点击的任务。
- 始终保留原始快捷方式点击时刻，同一方案的相对闹钟不会因为重连等待而整体推迟。
- 待执行任务只能领取一次；连续点击、重复连接回调不会创建两组闹钟。
- 任务等待超过 30 秒自动失效，避免很久以后意外补建闹钟。

首次初始化保留默认方案：8 小时后、8 小时 15 分钟后、8 小时 20 分钟后。旧版本保存的 480 / 495 / 500 分钟仍按原值读取，不改变实际含义；方案 ID 保留，因此已有快捷方式不会执行错方案。

## 配置能力

方案支持两种时间安排：

- 每个闹钟分别设置；
- 执行时选择时间＋间隔：方案不保存固定的第一个时间，只保存后续闹钟及其间隔。每次从应用内或桌面快捷方式执行时，先为本次第一个闹钟选择“从现在起”或“指定时间”。例如保存 15 分钟、5 分钟两个间隔，本次选择 18:00，会创建 18:00、18:15、18:20；没有后续间隔时只创建本次选择的第一个闹钟。

每个闹钟独立保存：

- “从现在起”的小时/分钟时长，或指定时分/日期；
- 完整重复规则（含自定义、单双休和 2～62 天轮班周期）；
- 名称；
- 系统/默认/天气/静音/自定义铃声和全部振动效果；
- 一次性关闭后删除；
- 稍后提醒开关、间隔、次数、稍后提醒报时（新建闹钟默认关闭）；
- 语音播报及天气、待办、快递、新闻的启用和顺序。

详细 APK 字段依据见 [vivo 配置项核对](docs/vivo-alarm-config-audit.md)。
