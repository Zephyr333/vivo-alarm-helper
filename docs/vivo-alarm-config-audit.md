# vivo 闹钟 8.0.3.10 配置项核对

目标设备：vivo X100 Pro（PD2324C）  
目标包：`com.android.BBKClock`  
目标版本：8.0.3.10

本文来自目标 APK 的 `Alarm`、`SetAlarm`、`SetAlarmFragment` 及各二级设置页。它用于约束本应用的数据结构和 Intent，不代表已经通过实机验收。

## 保存链

1. `SetAlarm.onCreate` 在 `intent_tag` 非空时调用内部参数解析并构造 `new Alarm(intent)`，随后只进入编辑页。
2. 右上角“完成”调用 `SetAlarmFragment.d2()`。
3. `d2()` 会补 UUID；轮班制会记录修改时间；任何重复闹钟都会把 `delete_after_ring_switch` 强制改为关闭；随后根据铃声 URI 和振动重新计算 `remindway`。
4. 新闹钟通过内部 `com.android.BBKClock.alarmclock.c.b(context, alarm, true)` 写入；编辑闹钟通过 `c.C(context, alarm)` 更新。
5. 写入后调用 `c.Y(activity, alarmId)` 安排下一次实际响铃。

这些内部方法不对第三方包开放。本应用继续使用已经通过实机验证的正常路径：把完整 `Alarm` 参数交给 `SetAlarm`，再由本应用无障碍服务只点击该页面的“完成”，从而让 vivo 自己完成写库和排程。

## Intent 字段

| 界面能力 | Extra | 类型 | 本应用编码 |
|---|---|---:|---|
| 时 | `hour` | int | 0～23 |
| 分 | `minutes` | int | 0～59 |
| 星期位图 | `daysofweek` | int | 周一至周日依次为 bit 0～6 |
| 重复类型 | `repeat` | int | 普通 0；单双休 1；轮班 5；法定工作日 6；节假日及周末 7 |
| 名称 | `message` | String | 最多 56 个 Unicode 字符 |
| 铃声 URI | `alert` | String | URI 字符串 |
| 铃声类别 | `default_ringtone` | int | 0 系统；1 跟随默认；2 天气；3 自定义；4 静音 |
| 振动效果 | `vibrate_mode` | int | 0 无；2 跟随音乐；1 标准；10～18 为九种效果 |
| 稍后提醒间隔 | `snooze` | String | 国内版 5/10/15/30 分钟 |
| 稍后提醒开关 | `alarm_remind_later_enable` | int | **反向编码**：0 开启，1 关闭 |
| 稍后提醒次数 | `alarm_remind_later_max_number` | int | 2/3/5/10 |
| 稍后提醒报时 | `snooze_talker` | int | 1 开启，0 关闭 |
| 语音播报 | `talker` | int | 1 开启，0 关闭 |
| 播报内容及顺序 | `broadcast_content` | String | A 天气、B 待办、C 快递、D 新闻；每项后接 1/0 |
| 关闭后删除 | `delete_after_ring_switch` | int | 一次性闹钟 1 开启 |
| 一次性日期 | `date_alarm` | String | `yyyy-MM-dd`；重复闹钟为空 |
| 法定节假日不提醒 | `china_holiday` | int | 1 开启，0 关闭 |
| 轮班当前日 | `shift_today` | int | 1～周期长度 |
| 轮班周期 | `shift_days_count` | int | 2～62 |
| 轮班各日时间 | `shift_days_time` | String | 逗号分隔的 `H:m` |
| 轮班各日启用 | `shift_days_enabled` | String | 逗号分隔的 1/0，至少一个 1 |

`enabled` 不需要由 Intent 提供：新闹钟在“完成”的内部保存分支中会设为启用。

## 页面可见配置与二级选项

- 时间规则：本应用明确分为“相对 t0”和“绝对时间”。两套值分别保存。
- 重复：仅一次、每天、法定工作日、节假日及周末、单双休工作日、轮班制工作日、自定义。
  - 单双休还需要指定本周为“双休（周一到周五）”或“单休（周一到周六）”。
  - 轮班周期为 2～62 天，指定今天是周期第几天，每个周期日独立设置时分和启用状态。
  - 自定义可独立选择周一至周日。
  - 每天、单双休、轮班制和自定义均可开启“智能跳过节假日”；法定工作日规则本身使用 vivo 的法定调休数据，节假日及周末规则则不显示此开关。
- 日期：仅一次时显示；vivo 日期选择范围是当前日期至约两年后。
- 闹钟名称：空值显示为“闹钟”，上限 56 个 Unicode 字符。
- 铃声：静音、跟随默认、天气（设备存在 weather 系统铃声时）、系统闹钟铃声、自定义音乐/录音。
- 振动：无振动、跟随音乐节奏、标准、舒缓、心动、蓝调、SOS、弹跳、呼唤、热舞、紧急、快速。
- 稍后提醒：总开关、5/10/15/30 分钟、2/3/5/10 次。
- 稍后提醒报时：仅在稍后提醒开启时有效。
- 语音播报：总开关；所在地天气、待办事项、待取快递、新闻资讯；支持启用、禁用和排序。
- 提醒关闭后删除：仅一次时可开；重复时 vivo 保存逻辑强制关闭。

## 明确联动

- 重复不是“仅一次”时，不使用 `date_alarm`，也不能开启关闭后删除。
- 轮班制的每个周期日有自己的时分，因此本应用只允许它使用绝对模式，不让相对偏移与轮班时分互相覆盖。
- 相对模式 + 普通重复：快捷方式执行时用同一 `t0 + offset` 得到时分，随后由 vivo 按重复规则计算下一次响铃；日期不参与。
- “跟随音乐节奏”只适用于跟随默认或系统铃声；天气、自定义或静音会由 vivo 改为标准振动。
- 关闭稍后提醒时，本应用同时把稍后提醒报时归一化为关闭。

## 必须实机核对的系统依赖

- 单双休的“本周单休/双休”还依赖 vivo 时钟私有的全局周状态。Intent 能保存 `repeat=1` 和当前星期位图，但需验证未手动进入 vivo 二级页时后续周是否正常轮换。
- 自定义铃声当前使用与 vivo 自定义铃声页相同的 MediaStore URI；需验证响铃时仍可长期读取。
- 天气铃声只在设备系统目录存在 `weather_*.ogg` 时展示。
- 天气播报依赖 vivo 天气和本地城市；待办依赖 vivo 时钟日历权限；快递依赖 Jovi 能力；新闻依赖 vivo 时钟联网许可。
- 部分 OriginOS 能力会在 `Alarm(Intent)` 构造时把 `C1`（待取快递）强制归一化为 `C0`。本应用保留该项目并明确提示，不静默承诺设备一定支持。
