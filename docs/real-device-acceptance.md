# 3.0 实机验收顺序

当前 APK 仅完成构建、签名和静态核对，尚未通过以下实机项目。

## 第一轮：入口与“不误执行”

- [ ] 覆盖安装后桌面只有一个固定主图标“vivo 闹钟方案”。
- [ ] 打开主图标只出现方案列表，不创建闹钟。
- [ ] 打开和保存“默认三闹钟”都不创建闹钟。
- [ ] 默认方案仍显示 +480、+495、+500。
- [ ] 旧版已经保存的偏移方案成功迁移。

## 第二轮：最小单闹钟

1. 新建方案“3 分钟测试”，只保留一个相对闹钟，偏移设为 +3 分钟。
2. 设置：仅一次、关闭后删除、默认铃声、标准或跟随音乐振动、稍后提醒 5 分钟 2 次。
3. 保存方案，确认没有创建闹钟。
4. 在列表点击“添加到桌面”，用桌面快捷方式执行。

- [ ] 快捷方式不回主应用确认，直接进入既有自动保存链。
- [ ] vivo 中只新增一个闹钟，时分与点击时刻 +3 分钟一致。
- [ ] 闹钟启用、仅一次、日期正确、关闭后删除开启。
- [ ] 响铃关闭后真实删除。

## 第三轮：默认和时间边界

- [ ] 默认快捷方式创建三个闹钟，三个目标都以一次点击时的同一个 t0 计算。
- [ ] 在接近午夜时，用较短偏移验证跨午夜日期。
- [ ] 一次性绝对日期时间正确；过期绝对时间明确报错且一个都不创建。
- [ ] 每天、自定义星期、法定工作日、节假日及周末逐项生效。
- [ ] 单双休本周类型及下一周轮换生效。
- [ ] 轮班周期、今天序号、各日时分和启用状态生效。

## 第四轮：逐项参数

- [ ] 名称。
- [ ] 静音、默认、系统铃声、天气铃声（若显示）、自定义音乐/录音。
- [ ] 12 种振动选择及不支持“跟随音乐”时的联动。
- [ ] 稍后提醒开关、四种间隔、四种次数。
- [ ] 稍后提醒报时。
- [ ] 语音播报总开关、天气、待办、快递、新闻、排序及相应权限提示。
- [ ] 一次性关闭后删除；重复时强制关闭。

## 第五轮：方案、快捷方式与持久化

- [ ] 多套方案互不混淆；各自快捷方式执行正确方案。
- [ ] 修改方案后旧快捷方式执行最新值。
- [ ] 删除方案后旧快捷方式不执行默认方案或其他方案。
- [ ] 强制停止、重启手机后配置仍在。
- [ ] 再次覆盖安装同包名同签名 APK 后配置仍在。
- [ ] 无障碍关闭、服务未连接、vivo 页面打不开、部分创建失败时均有明确提示。
